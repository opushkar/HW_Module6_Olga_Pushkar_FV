# Cat Info Processor (Task 2)

Проста програма на Python для читання та валідації даних про котів із текстового файлу.

## Функціонал
- Читання даних із формату `ID,Name,Age`.
- **Валідація ID:** Має бути рівно 24 символи.
- **Валідація віку:** Має бути числом у діапазоні від 0 до 55 років.
- **Обробка помилок:** Перевірка на існування та пустий файл.

## Як запустити проект

1. **Клонуйте репозиторій:**
   ```bash
   git clone <посилання-на-ваш-репозиторій>
   cd cat_project
   ```

2. **Налаштуйте віртуальне середовище:**
   - **Windows:**
     ```bash
     python -m venv .venv
     .\.venv\Scripts\activate
     ```
   - **macOS/Linux:**
     ```bash
     python3 -m venv .venv
     source .venv/bin/activate
     ```

3. **Встановіть залежності (якщо будуть додані в майбутньому):**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустіть програму:**
   ```bash
   python main.py
   ```

## Структура проекту
- `cat_processor.py` — модуль із логікою обробки даних.
- `main.py` — точка входу (запуск скрипта).
- `cats_data.txt` — файл із вхідними даними.
- `.gitignore` — список файлів, що ігноруються Git.
