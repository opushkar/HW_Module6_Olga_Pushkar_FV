# Аналізатор зарплат розробників

Цей проект дозволяє обчислити загальну суму та середній рівень заробітної плати з текстового файлу.

## Як запустити:
1. Створіть віртуальне середовище: `python -m venv .venv`
2. Активуйте його.
3. Підготуйте файл у `data/salaries.txt`.
4. Запустіть: `python main.py`

## Функціонал:
- Розподіл на модулі.
- Валідація імен та числових значень.
- Обробка винятків (відсутність файлу, биті дані).
