# Console Assistant Bot 🤖

Простий консольний бот-помічник для керування контактами. Проект демонструє модульну структуру Python, використання анотацій типів (Type Hinting), роботу з віртуальним середовищем та стилізацію консольного виводу за допомогою бібліотеки `rich`.

## Функціонал

Бот підтримує наступні команди:
- `hello` — привітання.
- `add [ім'я] [телефон]` — додавання нового контакту.
- `change [ім'я] [новий телефон]` — зміна існуючого номера.
- `phone [ім'я]` — пошук номера за ім'ям.
- `all` — вивід усіх збережених контактів.
- `close` або `exit` — завершення роботи.

## Вимоги

- Python 3.8+
- Бібліотека `rich`

## Встановлення та запуск

1. **Клонуйте репозиторій або скопіюйте файли:**
   ```bash
   git clone <url_вашого_репозиторію>
   cd assistant_bot
   ```

2. **Створіть та активуйте віртуальне середовище:**
   ```bash
   # Windows
   python -m venv venv
   venv\Scripts\activate

   # macOS / Linux
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Встановіть необхідні залежності:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустіть застосунок:**
   ```bash
   python main.py
   ```

## Структура проекту

- `main.py` — головний цикл бота та логіка взаємодії з користувачем.
- `handlers.py` — обробники команд та бізнес-логіка.
- `requirements.txt` — список зовнішніх залежностей.
- `.gitignore` — конфігурація ігнорування системних файлів Git.
