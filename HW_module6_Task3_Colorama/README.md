# Directory Visualizer

Скрипт на Python для візуалізації структури директорій у терміналі з використанням кастомних RGB-кольорів та діалогового вікна вибору папки.

## Функціонал
- 📂 **Візуалізація дерева**: Виводить ієрархію папок та файлів.
- 🎨 **RGB Кольори**: Папки відображаються синім (`110, 163, 248`), а файли — зеленим (`185, 237, 149`).
- 🖥️ **Діалогове вікно**: Якщо шлях не вказано в терміналі, відкривається вікно вибору директорії.
- 🧩 **Модульність**: Логіка візуалізації відокремлена від основного скрипту.

## Встановлення

1. **Клонуйте репозиторій або скопіюйте файли.**
2. **Створіть віртуальне оточення:**
   ```bash
   python -m venv venv
   ```
3. **Активуйте віртуальне оточення:**
   - Windows: `venv\Scripts\activate`
   - macOS/Linux: `source venv/bin/activate`
4. **Встановіть залежності:**
   ```bash
   pip install -r requirements.txt
   ```

## Використання

Ви можете запустити скрипт двома способами:

### Спосіб 1: Через діалогове вікно
Просто запустіть скрипт, і відкриється вікно вибору папки:
```bash
python main.py
```

### Спосіб 2: Передавши шлях як аргумент
Вкажіть шлях до конкретної папки прямо в команді:
```bash
python main.py "C:/Users/Documents/MyProject"
```
Або для поточної папки:
```bash
python main.py .
```

## Структура проєкту
- `main.py` — точка входу, обробка аргументів та запуск GUI.
- `directory_visualizer.py` — логіка рекурсивного обходу та кольорового виводу.
- `requirements.txt` — список необхідних бібліотек.
- `.gitignore` — список файлів, що ігноруються Git.
